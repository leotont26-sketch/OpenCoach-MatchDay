# OpenCoach · MatchDay ⚽

Modernes Turniermanagement für Jugend- und Amateurfußball.  
Einfach. Schnell. Ohne Datenbank. Ohne Werbung. Ohne Abo.  

---

## 📌 Was ist MatchDay?

**MatchDay** ist ein webbasiertes Turnier-Tool für Fußballvereine, Trainer und Organisatoren.

Es hilft dabei:
- Turniere in wenigen Minuten zu erstellen
- automatische Spielpläne zu generieren
- Spiele live zu verwalten
- Ergebnisse zentral oder durch Schiedsrichter einzutragen
- Turniere auf TV/Bildschirm darzustellen
- PDFs für Aushang oder Zuschauer zu exportieren

Das Ganze läuft auf einem einfachen Webspace mit PHP.  
Keine Datenbank. Keine Registrierung. Keine Cloud-Pflicht.

5. Fertig

## 📡 Installations- & Statusübermittlung

MatchDay/SquadTrack kann optional technische Installations- und Statusinformationen an die zentrale OpenCoach-Instanz übermitteln.

Dies dient ausschließlich:
- Versionsübersicht
- Fehleranalyse
- Reichweitenabschätzung
- Verbesserung der Software

Es werden keine personenbezogenen Daten übertragen.

Übermittelt werden:
- installierte Version
- PHP-Version
- Modulname
- Statusinformationen
- Domain

Die Übermittlung kann jederzeit in der install_report.php deaktiviert werden.
